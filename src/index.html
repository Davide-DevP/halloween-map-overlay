Frequently asked questions
The overlay does not show over the game

Set Halloween: The Game to Borderless Windowed in its video settings. In exclusive fullscreen Windows gives the game exclusive control of the screen and no overlay window can draw on top of it.

Can the app get me banned?

It only displays image files that ship with it. It never reads the game's memory, never injects anything and never touches the game process in any way.

Does it take screenshots?

Only if you switch Auto-detect map on, and it is off by default. While it is on, the app takes a screenshot of the display you selected under Settings → Overlay → Monitor every 2 seconds and compares it, on your own computer, against four small thumbnails of the in-game maps that ship inside the app. Nothing is saved to disk and nothing is uploaded — the only thing kept from a screenshot is which map it matched. Switch it off and no screenshot is ever taken. Note that taking the screenshot is currently expensive enough to make the machine stutter every couple of seconds on some systems; if you notice that, leave the switch off.

Does it use the internet?

Once, at startup: it asks GitHub whether a newer version of this app has been released, and nothing else. No accounts, no telemetry, no analytics. The map images are inside the app and are never downloaded. You can turn the check off under Settings → General → Check for updates on startup, after which the app makes no network requests at all.

How does auto-detect work?

Switch Auto-detect map on above the gallery, then press Tab in the game once at the start of a match. The overlay switches to that map and names it for a few seconds. It only acts when it sees a different map, so picking one by hand or with a hotkey overrides it and it will not switch back. Press Ctrl + Shift + D to clear the map and make it forget what it saw, so the next Tab press detects the same map again.

The overlay is in the way

Press Ctrl + H to hide it, or move and resize it under Settings → Overlay.

How do I record it in OBS?

Press Open OBS window, then capture that window in OBS and key out the green background with a chroma-key filter.

Can I add my own map images?

Yes — Add custom image in the menu. They appear in the gallery under the Custom creator.
