This session runs on Wayland, where dragging the overlay does not work. Use the fine-grain position sliders instead.

Frequently asked questions
The overlay does not show over the game

Set Halloween: The Game to Borderless Windowed in its video settings.

Can the app get me banned?

It only displays image files that ship with it.

Does it take screenshots?

Only if you switch Auto-detect map on, and it is off by default.

Does it use the internet?

Once, at startup: it asks GitHub whether a newer version of this app has been released, and nothing else.

How do updates work?

When a newer version exists it is downloaded quietly in the background.

If an update still drags, what is left is usually your antivirus reading every unpacked file.

How does auto-detect work?

Switch Auto-detect map on above the gallery, then press Tab in the game once at the start of a match.

The overlay is in the way

Press Ctrl + H to hide it.

How do I record it in OBS?

Press Open OBS window, then capture that window in OBS.

Can I add my own map images?

Yes — Add custom image in the menu.
