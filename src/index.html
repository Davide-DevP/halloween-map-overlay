Frequently asked questions
The overlay does not show over the game

Set Halloween: The Game to Borderless Windowed in its video settings — that is the mode the overlay is built for. The overlay is an always-on-top window, so the game has to be a window too; and a game window with a border or a title bar also stops the markers being drawn on the game's own map.

Can the app get me banned?

It only displays image files that ship with it. It never reads the game's memory, never injects anything and never touches the game process in any way.

Does it take screenshots?

Only if you switch Auto-detect map on, and it is off by default. While it is on and the game is running, the app captures the game's own window — not your screen, not any other window — about every 0.7 seconds. While the game is not running it only checks every 2 seconds whether that window has appeared yet, and captures nothing. It compares that image, on your own computer, against small thumbnails of the in-game maps that ship inside the app. Nothing is saved to disk and nothing is uploaded: the only thing kept is which map it matched. Switch it off and nothing is captured at all. With markers on the in-game map also on there are a few more of those captures while you are holding your map key: with the key trigger, one when you press it plus a twice-a-second check while the markers are actually up; without it, every 0.45 s and about six times a second while they are up. Separately, the hotkey setting Only while the game is in the foreground looks once a second at the list of open windows and reads, for each one, its program name, its window title, its size and whether it has the keyboard — no pixels, nothing captured and nothing kept.

Does it read my keyboard?

It reads one key, and only with markers on the in-game map switched on — which is off by default — and the game running. Switching that mode on makes the app check once that Windows lets it ask at all; that check reads no key. After that, each time, it first asks Windows which program owns the window you are working in; if that is not the game it stops there and no key is read at all. If it is the game, it asks "is the map key held right now?": the one key you set under Game's map key, plus Alt while that key is held, so Alt + Tab is not mistaken for you opening the map. There is no keyboard hook — the app does not receive keystrokes, cannot see what you type, and never asks about any other key. Nothing is written down except that your map key went down or came up. It does not reserve the key either, so the game still sees every press. Pressing it is also never enough on its own: a press only makes the app look at the game's window, and the markers appear only if what it sees really is the map screen. Switch that mode off, or switch on Do not read the key state, and nothing is read at all. Everything else the app does with the keyboard is its own hotkeys, which you choose and can unbind.

Does it use the internet?

For two things, both of them a plain request for a public file on GitHub and nothing else. Updates: at startup it asks whether a newer version of this app has been released. New maps: at startup, and then at most once a day, it asks whether new or corrected map images exist — the maps that ship inside the app never change on their own, but the game gets new ones. No accounts, no telemetry, no analytics, nothing about you or your PC is sent either time. Each has its own switch under Settings → General, and with both off the app makes no network requests at all.

How do new maps arrive?

The game gets new maps more often than this app gets a release, so each map is downloaded separately: a few hundred KB of image and detection data, checked against a published checksum before it is stored, instead of a 90 MB app update. It appears in the gallery straight away — no restart — and auto-detect learns it at the same moment. A download that is incomplete or does not match its checksum is thrown away whole and the map you already had is left alone. Turn it off under Settings → General → Check for new maps.

How do updates work?

When a newer version exists it is downloaded quietly in the background, and then a green banner appears at the top of this window. Nothing is installed until you press Restart and update there (or in the tray menu). The app then closes and a small window in the app's own colours takes its place, showing the steps and a progress bar; it works the disk for a few seconds, and then the app reopens by itself. The installer runs at low priority, so the rest of the PC stays responsive while it unpacks. If that window cannot start for any reason, the plain Windows installer runs instead — the update still happens. You are not asked anything and Windows does not prompt for permission — it installs only for your own user account. Press Later and the banner goes away for now; the update stays waiting for the next time you start the app. Closing or quitting the app never installs anything. The check itself only runs at startup, so if the app has been open for a while, Settings → General → Check for updates now asks again on the spot — the same single request, and it works even with the startup switch off.

If an update still drags, what is left is usually your antivirus reading every unpacked file. Adding %LOCALAPPDATA%\Programs\Halloween Map Overlay to the exclusions under Windows Security → Virus & threat protection → Manage settings → Exclusions removes that cost.

Welcome

This app puts the map you are playing on top of the game, in a corner you choose, and lets you hide it or switch maps with a keyboard shortcut. A few short steps and you are set — you can skip them and change everything later under Settings.

Applies straight away — no restart. Map and creator names are never translated.

Where the map goes

Pick the screen, the corner and how big the map should be. Its opacity, rotation and a finer position are under Settings → Overlay, and you can also drag it into place by hand.

A sample map is on the overlay right now, so you can see exactly where it lands while you change these.
The corner is fixed while Overlay draggable is on — you are placing the overlay by hand. Switch that off under Settings → Overlay to pick a corner again.

What the markers mean

The overlay marks where the game may put the ways out and the gas cans — never where they are. A different subset is active each match, so read a marker as "worth checking".

The ways out are already drawn on the map images; the yellow gas-can markers are the ones this app adds. Each kind has its own switch under Settings → Overlay.

Your hotkeys

These are the combinations the app starts with. Every one of them can be changed, or switched off entirely, under Settings → Hotkeys — and each map has its own number key.

They are reserved only while Halloween: The Game — or this window — is in front, so the rest of the time those combinations still belong to your other programs.

That was it — the shortcut reached the app.

Let it follow the game

With this on, press Tab in game once at the start of a match: the overlay switches to the map you are playing and names it for a few seconds. It also clears the overlay when you are back in the main menu. It stays off unless you turn it on.

To do that it reads the game's own window — not your screen, not any other window — a few times a second while the game is running. The picture never leaves this PC: nothing is saved to disk, nothing is uploaded, and the only thing kept is which map it matched.

Markers on the in-game map (experimental)

Experimental, and off unless you turn it on: hold your map key in game and the possible locations appear on the game's own big map — the one with your position on it.

While this is on and the game is the window in front, the app asks Windows whether that one key is held right now. It never receives, records or sees any other key, it does not take the key away from the game, and nothing is stored or sent.

That is everything

The rest lives under Settings in the menu bar: the overlay's position, size and opacity, every hotkey, the language and the OBS window. FAQ next to it answers the questions this tour skipped.
