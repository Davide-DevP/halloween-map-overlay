Frequently asked questions
What does the app read?

Two things, and only when you have asked for them. The game's picture: with Recognise the map automatically on, the app looks at the game's window, not at your screen and not at any other window, to work out which map you are playing. One key: with the game's map chosen, and only while the game is the window in front, it asks Windows whether your map key is down right now. Nothing is saved and nothing is sent. No other key is ever read, and the game's memory is never touched.

Technically: the picture is compared on your PC against small thumbnails that ship inside the app, then thrown away; the key is one GetAsyncKeyState call, with no keyboard hook, and the key is not reserved, so the game still gets every press.

The map does not show over the game

Set Halloween: The Game to Borderless Windowed in its video settings: that is the mode this app is built for. The map is an always-on-top window, so the game has to be a window too. A game window with a border or a title bar also stops the points being drawn on the game's map.

Can the app get me banned?

It only shows image files that come with the app. It never reads the game's memory, never adds anything to the game and never touches the game's own program in any way.

Does it take screenshots?

Only if you switch Recognise the map automatically on, and it is off by default. While it is on and the game is running, the app captures the game's own window, not your screen and not any other window, about every 0.7 seconds. While the game is not running it only checks every 2 seconds whether that window has turned up yet, and captures nothing. It compares that picture, on your own computer, against small thumbnails of the game's maps that ship inside the app. Nothing is saved to disk and nothing is uploaded: the only thing kept is which map it matched. Switch it off and nothing is captured at all. If you also chose On the game's map there are a few more of those captures while you hold your map key down: with the key reading, one when you press it plus a twice-a-second check while the points are actually up; without it, every 0.45 s and about six times a second while they are up.

Separately, the hotkey setting Active only while I am in the game looks once a second at the list of open windows and reads, for each one, its program name, its window title, its size and whether it has the keyboard: no pixels, nothing captured and nothing kept.

Does it read my keyboard?

It reads one key, and only if you chose On the game's map, which is off until you choose it, and the game is running. Choosing that mode makes the app check once that Windows lets it ask at all; that check reads no key. After that, each time, it first asks Windows which program owns the window you are working in; if that is not the game it stops there and no key is read at all. If it is the game, it asks "is the map key held right now?": the one key you set under The game's map key, plus Alt while that key is held, so Alt + Tab is not mistaken for you opening the map. There is no keyboard hook: the app does not receive keystrokes, cannot see what you type, and never asks about any other key. Nothing is written down except that your map key went down or came up. It does not reserve the key either, so the game still sees every press. Pressing it is never enough on its own: a press only makes the app look at the game's window, and the points appear only if what it sees really is the map screen. Choose another place for the map, or switch on Use the other method, and nothing is read at all.

Everything else the app does with the keyboard is its own hotkeys, which you choose and can remove.

Does it use the internet?

Only to check two things: whether a newer version of the app exists, and whether new or corrected maps exist. Nothing about you or your PC is ever sent: no accounts, no telemetry, no analytics. Nothing is installed unless you say so. One switch under Settings → General turns both off, and with it off the app makes no network requests by itself. Technically: two plain HTTPS requests for a public file on GitHub, the second at most once a day.

How do new maps arrive?

The game gets new maps more often than this app gets a new version, so each map is downloaded separately: a few hundred KB of image and recognition data, checked against a published checksum before it is stored, instead of a 90 MB app update. It turns up in the gallery straight away, with no restart, and the app learns to recognise it at the same moment. A download that is incomplete, or that does not match its checksum, is thrown away whole and the map you already had is left alone. You can turn it off under Settings → General → Check for updates automatically.

How do updates work?

When a newer version exists it is downloaded quietly in the background, and then a green banner appears at the top of this window. Nothing is installed until you press Restart and update there, or on the icon near the clock. The app then closes and a small window in the app's own colours takes its place, showing the steps and a progress bar; it works the disk for a few seconds, and then the app reopens by itself. The installer runs at low priority, so the rest of the PC stays responsive while it unpacks. If that window cannot start for any reason, the plain Windows installer runs instead and the update still happens. You are not asked anything and Windows does not ask for permission: it installs only for your own user account. Press Later and the banner goes away for now; the update stays waiting for the next time you start the app. Closing or quitting the app never installs anything. The check itself only runs when the app starts, so if the app has been open for a while, Settings → General → Check now asks again on the spot: the same single request, and it works even if Check for updates automatically is off.

If an update is still slow, what is left is usually your antivirus reading every unpacked file. Adding %LOCALAPPDATA%\Programs\Halloween Map Overlay to the exclusions under Windows Security → Virus & threat protection → Manage settings → Exclusions removes that cost.
